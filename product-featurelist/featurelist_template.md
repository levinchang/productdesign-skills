## 列名说明速查

| 列名 | 说明 |
|------|------|
| Mark | DONE/READY/REVIEW 等状态，由项目定 |
| 编号 | 与 PRD 索引一致，如 `WB-DM-1.1`、`MP-OPS-1.3` |
| 领域（Domain） | 最顶层业务域 |
| 一级（菜单/模块） | 领域下的一级导航/模块 |
| 二级（菜单/页面） | 模块下的主页面或主入口 |
| 功能（页内能力） | 页面内可独立评审的能力点 |
| 子功能（可选） | 仅在功能仍偏大时补充拆分 |
| 描述 | 功能说明或用户故事 |
| 负责产品 | 负责人/角色 |
| 必要性 | Must/Should/Nice to/Maybe 等 |
| 涉及端 | Web 管理端、触摸屏、设备端、小程序、手机 App、PC 客户端 等；用于表达实际影响端，可多值 |
| 期望版本 | V1.0、V2.0、OTA 等 |
| 说明 | 补充说明、约束 |
| 备注 | 依赖、风险、待定 |
