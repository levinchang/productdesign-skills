## 列名说明速查

| 列名 | 说明 |
|------|------|
| Mark | DONE/READY/REVIEW 等状态，由项目定 |
| 编号 | 与 PRD 索引一致，如 1.1.1、2.3.4 |
| 〇级（领域） | 最顶层产品域 |
| 一级（模块） | 领域下模块 |
| 二级（能力） | 模块下能力 |
| 三级（功能） | 具体功能点 |
| 四级（子功能） | 可选子功能 |
| 描述 | 功能说明或用户故事 |
| 负责产品 | 负责人/角色 |
| 必要性 | Must/Should/Nice to/Maybe 等 |
| 涉及端 | 管理端、触摸屏、设备端、小程序、手机 App、PC 客户端 等 |
| 期望版本 | V1.0、V2.0、OTA 等 |
| 说明 | 补充说明、约束 |
| 备注 | 依赖、风险、待定 |
