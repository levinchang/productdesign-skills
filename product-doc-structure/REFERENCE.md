# 产品文档结构规范 - 参考模板

本文件提供可直接复用的文档模板，便于按规范快速创建 PRD 与根 README。**路径、编号、模块名等需按当前项目约定替换**。详细规则见 [SKILL.md](./SKILL.md)。

---

## 一、PRD 单文档模板（复制到新 .md 后填空）

```markdown
# <模块编号或功能名> <功能名称>

| 项目 | 说明 |
|------|------|
| **功能名称** | （与标题一致） |
| **对应 FeatureList** | （与项目编号体系一致，如 1.1.1、M1.1、F2.3） |
| **对应 ER 实体** | （表名或实体名，如有） |
| **对应时序图** | （如有，如 时序图01） |

---

## 1. 需求背景与目标

（为何做、做什么、期望效果；可含用户故事、验收标准 AC）

---

## 2. 角色与入口

（谁、从哪进、数据范围）

---

## 3. 页面结构与交互

（布局、区块、操作、状态）

---

## 4. 字段规格表

（必填/长度/格式/取值来源/校验/错误提示；键名与 ER 一致）

| 字段 | 必填 | 长度/格式 | 取值来源 | 校验 | 错误提示 |
|------|------|-----------|----------|------|----------|
|     |      |           |          |      |          |

---

## 5. 业务逻辑与状态流转

（规则、状态机、流程；可引用时序图）

---

## 6. 异常与边界

（加载中、失败、空态、权限、网络等）

---

## 7. 依赖与待定项

（依赖接口/模块；待产品与后端约定的项）
```

---

## 二、文档根目录 README 结构建议

```markdown
# <项目/产品名> 产品与研发文档

（一句话产品简介）

---

## 文档目录结构

（按当前项目实际目录与命名填写，可参考 SKILL 中的示例树）

---

## 文档使用说明

| 文档类型 | 用途 | 与 PRD 关系 |
|----------|------|-------------|
| Feature List | 功能范围、优先级、编号 | 每个 PRD 头部注明对应编号 |
| ER 图 | 数据表与字段、关系 | PRD 字段键名与 ER 一致 |
| 时序图 | 关键流程 | PRD 流程逻辑可引用 |
| tech/* | 技术方案 | 开发实现依据 |
| PRD 目录 | 需求规格 | 按 PRD 实现；通过索引表按编号反查路径 |
```

---

## 三、PRD 索引表格式（在 PRD 根或各子域 README 中维护）

**索引表**（必须维护，列名可微调）：

| FeatureList 编号 | 功能简述 | PRD 文件路径 |
|------------------|----------|--------------|
| （编号） | （简述） | （相对文档根或 PRD 根的路径，如 模块目录/功能文件_PRD.md） |
| … | … | … |

- 若 PRD 按多子域拆分，可在各子域 README 各维护一张表，或在 PRD 根 README 汇总。
- 可选补充：UI/设计规范（布局、主色、组件）、模块与菜单/页面映射。

---
